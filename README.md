# TP-1
JavaScript Avancé – TP (Mini-Projet et Exercices)

Repository containing exercises and a mini-project for an advanced JavaScript workshop. Focus areas include:

Modern ES6+ syntax (let, const, arrow functions, destructuring, spread/rest)

Object manipulation, classes, and array methods (map, reduce, filter, sort)

Asynchronous programming with Promises, async/await, and fetch API

A small interactive mini-project demonstrating DOM manipulation and API usage

Structure:

Partie 1 – ES6 Basics: Variables, functions, destructuring, spread operator

Partie 2 – Objects & Classes: Object methods, ES6 classes, advanced array operations

Partie 3 – Asynchronous JS: Promises, async/await, API fetch
